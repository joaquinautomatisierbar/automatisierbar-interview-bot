TEIL 1 · GRUNDLAGEN // DIE DEFINITION

Cybersecurity heisst: Daten und Systeme schützen. Vor drei Dingen.

🕵️

Stehlen

Jemand liest oder kopiert, was ihn nichts angeht.

✏️

Verändern

Jemand manipuliert Zahlen, Verträge oder Zahlungen. Klassiker: die Kontonummer auf einer Rechnung.

🧱

Lahmlegen

Jemand sorgt dafür, dass nichts mehr funktioniert.

Jede Massnahme, die heute kommt, schützt vor mindestens einem dieser drei Dinge.

TEIL 1 · GRUNDLAGEN // WARUM KMU

Es meint dich niemand persönlich. Das ist die schlechte Nachricht.

🤖 Angriffe sind Massenware

🎯 Die einzige Frage

Nicht: «Sind wir interessant?» Sondern: «Stehen wir offen?» Offene Tür = Treffer, egal wie klein die Firma ist.

Die Frage ist nicht, ob man interessant ist. Die Frage ist, ob man offen steht.

TEIL 1 · GRUNDLAGEN // KURZER GRUNDKURS

Wo wohnt eine Software?

SERVER

Ein Computer, der nie ausgeschaltet wird und nur dafür da ist, eine Software laufen zu lassen.

RECHENZENTRUM

Ein bewachtes Gebäude voller Server: Strom doppelt, Kühlung, Zutrittskontrolle.

CLOUD

Heisst nur: du mietest Server in so einem Gebäude, statt eigene zu kaufen. Kein Nebel, ein Ort.

BROWSER

Dein Fenster dorthin (Chrome, Safari, Edge): die Software läuft dort, du bedienst sie von hier.

Merke: «Wo liegen unsere Daten?» hat damit eine konkrete Antwort: auf bestimmten Servern, in einem bestimmten Gebäude, an einem bestimmten Ort.

BEGRIFF // DAS DING HAT EINEN NAMEN

Ransomware.

Ransomware = Erpressungs-Software (englisch ransom = Lösegeld). Sie verschlüsselt alle Daten und verkauft dir deinen eigenen Schlüssel zurück.

💸 Warum Zahlen keine Lösung ist

Keine Garantie auf den Schlüssel. Du finanzierst den nächsten Angriff. Und die Daten wurden vorher kopiert (Szene 3): die Erpressung geht oft weiter.

🛟 Die echte Antwort

Vorbereitung: eine Sicherungskopie, die der Angreifer nicht erreichen kann. Kommt in Teil 4.

TEIL 3 · RING 1 · IDENTITÄT // WERKZEUG 1

Der Passwort-Manager.

Passwort-Manager = ein Tresor-Programm: erzeugt für jeden Dienst ein eigenes, langes Zufallspasswort. Du merkst dir genau eines: das für den Tresor.

🛡️ Der unterschätzte Bonus

Der Tresor füllt Passwörter nur auf der echten Adresse aus. Auf rnicrosoft-support.com bleibt das Feld leer. Das Auge lässt sich täuschen, der Tresor nicht.

✂ BRICHT GLIED 2 · DER KLICK AUF DIE FAKE-SEITE

Bei uns Pflicht auf jedem Gerät. In der Hausaufgabe prüfst du deinen eigenen Passwort-Tresor.

TEIL 3 · RING 1 · IDENTITÄT // WERKZEUG 2

MFA: der zweite Schlüssel.

MFA (Multi-Faktor-Authentifizierung) = zusätzlich zum Passwort braucht es einen zweiten Beweis, z. B. die Bestätigung auf deinem Handy. Ein gestohlenes Passwort allein ist damit wertlos.

TEIL 3 · RING 2 · GERÄT // WERKZEUG 1 · STEHT WÖRTLICH IN DER ANFRAGE

EDR: vom Türsteher zum Wachhund.

🪪 Klassischer Virenscanner

Türsteher mit Fahndungsfotos: erkennt nur Schädlinge, die er schon kennt. Neues Schadprogramm? Kommt durch.

🐕 EDR

Wachhund: beobachtet Verhalten. «Warum verschlüsselt Excel gerade 3’000 Dateien?» Schlägt an und kann das Gerät sofort vom Netz trennen (isolieren).

EDR (Endpoint Detection & Response) = Erkennen und Reagieren am Endgerät. Endpoint = jedes Endgerät (Laptop, Handy, Server). Das Wort in der Anfrage: EndpointSecurity.
✂ BRICHT GLIED 4+5 · DIE MASSENVERSCHLÜSSELUNG AUS SZENE 4 FLIEGT AUF

EDR heisst: Das Gerät wird beobachtet, nicht nur gescannt. Auffälliges Verhalten wird erkannt, und das Gerät kann isoliert werden.

TEIL 3 · RING 2 · GERÄT // WERKZEUG 2

Geräteverschlüsselung: der Laptop im Zug.

😱 Ohne Verschlüsselung

Der Finder baut die Festplatte aus und liest alles: Mails, Verträge, gespeicherte Passwörter.

🧱 Mit Verschlüsselung

Der Finder hat einen Briefbeschwerer. Ohne deinen Login ist alles Zeichensalat.

Verschlüsselung = Daten werden zu Zeichensalat, lesbar nur mit dem Schlüssel. Dieselbe Technik wie in Szene 4, nur: hier haben wir den Schlüssel, nicht der Angreifer.
⚠ ANDERER EINBRUCHSWEG · VERLUST + DIEBSTAHL

Heisst bei Windows BitLocker, beim Mac FileVault. Hausaufgabe: prüfen, ob es bei dir an ist.

TEIL 3 · RING 3 · NETZ // DIE MODERNE ANTWORT · [BEI ZEITNOT ÜBERSPRINGEN]

Zero Trust: Türsteher an jeder Tür.

🏰 Die Burg (VPN-Denken)

Einmal über die Zugbrücke, dann freie Bahn im ganzen Netz. Wird ein Gerät gekapert, steht alles offen.

🚪 Zero Trust («null Vertrauen»)

Keine Burg. Jede Anwendung prüft dich einzeln: Wer bist du? Ist dein Gerät gesund? Erst dann öffnet genau diese eine Tür.

Keine Theorie: Microsoft selbst ersetzt das Voll-VPN durch Zero Trust. Zahlen und Daten dazu: Anhang A2.

Für den mobilen Zugriff positioniert Microsoft heute Zero Trust als Nachfolger des Voll-VPN; das ordnen wir gerne ein, bevor jemand teuren Alt-Betrieb offeriert.

TEIL 3 · RING 4 · ZUGRIFF & DATEN // WERKZEUG 1

Rollen statt Vertrauen.

Rollen-Prinzip (Fachwort: RBAC) = Rechte hängen an Rollen, nicht an Personen. Plus Least Privilege = jede Rolle bekommt nur das Minimum, das sie braucht.
Rolle bei vRvDarf
AdministrationAlles verwalten, Rechte vergeben
SachbearbeitungAufträge + Rechnungen der eigenen Mandate
HauswartNur die eigenen Liegenschaften + Aufträge, keine Buchhaltung
RevisionAlles lesen, nichts ändern (die Prüfer-Rolle)

Gilt auch für uns selbst: jeder bei Automatisierbar sieht nur das Minimum. Das ist die Antwort auf «Wer bei Ihnen hat Zugriff auf unsere Daten?»

TEIL 3 · RING 4 · ZUGRIFF & DATEN // WERKZEUG 2

Das Audit-Log: das Kassenbuch der Plattform.

Audit-Log = automatisches Journal: wer hat wann was gemacht (Anmeldungen, Rechte-Änderungen, Exporte, Freigaben). Mitgeschrieben, nicht wegdiskutierbar.

🌙 Zurück zu Szene 3: «Niemand merkt es.»

Mit Audit-Log stimmt der Satz nicht mehr: der Login um 02:10, Standort unbekannt, steht im Log. Schwarz auf weiss, mit Zeitstempel.

✂ BRICHT «NIEMAND MERKT ES» · SZENE 3 WIRD SICHTBAR

ANHANG · NUR ZUM NACHSCHLAGEN // A1

Always On VPN: die Technik dahinter.

Device Tunnel VOR DEM LOGIN

Verbindet, sobald das Gerät startet. Nur Protokoll IKEv2, nur für Firmen-PCs in der Domäne (domain-joined).

User Tunnel NACH DEM LOGIN

Verbindet, wenn sich die Person anmeldet. Der Normalfall für Benutzer-Zugriff.

Dahinter dauerhaft zu betreiben:

RRAS · DER VPN-SERVER NPS/RADIUS · AUTHENTIFIZIERUNG (EAP-TLS) PKI · ZERTIFIKATE AUF JEDES GERÄT

Nachfolger des abgekündigten DirectAccess. Typische Störungen (abgelaufene Zertifikate) sind sofort P1 = höchste Prioritätsstufe. Darum: Betrieb beim IT-Partner.
