# Juglans Offerten-Generator, Installation

Guten Tag Herr Busslinger

Hier ist Ihr persönliches Offerten-Programm. Es läuft komplett auf Ihrem
Computer, ganz ohne Internet. Die Installation dauert rund zwei Minuten. Sie
brauchen nichts einzurichten, einfach den fünf Schritten folgen.

---

### Schritt 1: USB-Stick einstecken
Stecken Sie den mitgelieferten USB-Stick in Ihren Computer. Es öffnet sich ein
Fenster mit dem Inhalt des Sticks. Falls nicht, öffnen Sie unten links das
Ordner-Symbol und klicken links auf **Dieser PC**, dann doppelklicken Sie auf den
USB-Stick.

### Schritt 2: Installation starten
Doppelklicken Sie auf die Datei **JuglansOfferten-Setup**.

### Schritt 3: Windows-Hinweis bestätigen
Wenn ein blaues Fenster erscheint mit «Der Computer wurde durch Windows
geschützt»:
1. Klicken Sie auf **Weitere Informationen**.
2. Klicken Sie dann auf **Trotzdem ausführen**.

Das ist normal und sicher. Windows zeigt diesen Hinweis bei jedem neuen Programm.

### Schritt 4: Auf «Installieren» klicken
Folgen Sie dem Installationsfenster und klicken Sie auf **Installieren**. Lassen
Sie das Häkchen bei «Desktop-Verknüpfung erstellen» gesetzt. Am Ende auf
**Fertigstellen** klicken.

### Schritt 5: Programm öffnen
Auf Ihrem Desktop (Startbildschirm) erscheint ein neues Symbol
**Juglans Offerten-Generator**. Doppelklicken Sie darauf. Das Programm öffnet
sich nach ein paar Sekunden in Ihrem Browser-Fenster. Fertig.

---

### So arbeiten Sie damit
- Füllen Sie den kurzen Projekt-Fragebogen aus (was steht an, welche Masse).
- Klicken Sie auf **Intelligente Vorschläge generieren**. Das Programm schlägt
  Ihnen passende Positionen aus Ihren früheren Offerten vor.
- Wählen Sie an, was passt, ergänzen Sie die Mengen, und laden Sie die fertige
  Offerte als Excel herunter.

Alles bleibt auf Ihrem Computer. Ihre Offerten und Entwürfe werden lokal
gespeichert.

### Gut zu wissen
- **Der erste Klick auf «Vorschläge generieren» dauert etwas länger**, danach geht
  es schneller. Bitte einen Moment Geduld.
- Zum Schliessen einfach das Browser-Fenster zumachen. Beim nächsten Mal wieder
  auf das Desktop-Symbol doppelklicken.
- Über das Feld **Feedback an Automatisierbar** (unten links) können Sie uns
  Wünsche mitgeben. Die Nachricht wird gespeichert und erreicht uns beim nächsten
  Update.

### Wenn etwas nicht klappt
Rufen Sie uns an oder schreiben Sie an **info@automatisierbar.ch**. Wir helfen
Ihnen gerne weiter.
