# Suggest LinkedIn Image

Every LinkedIn post needs at least one image — engagement halves without one. This skill enforces brand-aligned, anti-stock suggestions.

## The 2 image kinds (the ONLY allowed kinds)

### `kind: "auto-svg"` — brand-aligned text card

Used when there's no real screenshot/asset that fits.

Output spec:
```json
{
  "kind": "auto-svg",
  "spec": {
    "headline": "5h pro Woche zurück",
    "subtitle": "Treuhand · Beleg-Eingang automatisiert",
    "palette": "green-on-deep"
  },
  "rationale": "Echoes the post's #1 concrete number (5h) and the named industry (Treuhand). Deep-green background asserts quiet professionalism."
}
```

Headline rules:
- ≤6 words
- Carries the post's single most important number or claim
- Hochdeutsch
- No buzzwords

Subtitle rules:
- ≤10 words
- Adds context (industry / specific process / role)
- Optional — leave empty if headline stands alone

Palette options (lifted from `~/_context/Automatisierbar_Brand_Guide EXTERN copy.pdf`):
- `green-on-deep` — Primary Green text (#15C97A) on Primary Deep (#063D25) background. Most professional, recommended default.
- `deep-on-light` — Primary Deep text on Primary Light (#D4F7E9). Lighter feel, good for soft topics.
- `green-on-offwhite` — Primary Green text on Off-White (#F4FCF8). Neutral, content-first.
- `white-on-black` — Off-White on Neutral Black (#0C1410). Use for "we got something wrong" / vulnerability posts.

### `kind: "existing-asset"` — reference a real image

Used when there's a real Automatisierbar / customer-approved asset that grounds the post in actual operations.

Output spec:
```json
{
  "kind": "existing-asset",
  "path": "static/screenshots/notion-priority-inbox.png",
  "rationale": "Real product screenshot shows the customer-facing surface (Notion priority view). Grounds the post in actual operations, not concept."
}
```

Path rules:
- Repo-relative path
- Must be a file that actually exists OR is described as "to be generated by Engineer in a future build"
- NO stock-photo URLs
- NO Unsplash, Pexels, Pixabay, AI-image-gen URLs

## What's FORBIDDEN

- Stock photos (Unsplash, Pexels, generic SaaS marketing photography)
- AI-generated faces (LinkedIn's algorithm is downranking these in 2026)
- Images of "happy office workers in a meeting"
- Generic gradient backgrounds with no message
- Customer faces without explicit customer release
- The Automatisierbar logo as the post image (logo goes in subtitle, not main image)

## When to suggest 2 images instead of 1

Suggest 2 images when:
- Long posts (>1000 chars) with two distinct beats — image at top + image after the recipe
- Proof posts (case studies) — auto-svg with the result number AT TOP + screenshot of the deliverable BELOW
- Contrarian posts (H2/H6) — one auto-svg with the contrarian claim + one supporting visual

For short posts (<500 chars): always just 1 image.

## How to decide auto-svg vs existing-asset

| Post type | Recommended kind |
|---|---|
| Numbered observation / "X out of Y" stat | `auto-svg` with the stat as headline |
| Named-customer proof | `existing-asset` (real screenshot) if available, else `auto-svg` with the number + customer-name |
| Recipe / how-to | `auto-svg` with the recipe's final-step outcome |
| Vulnerability / mistake post | `auto-svg` with the lesson as headline, palette `white-on-black` |
| Contrarian opinion | `auto-svg` with the contrarian claim, palette `green-on-deep` |
| Process diagram showcase | `existing-asset` pointing to `process-diagram.svg` from a related Build Issue, IF available |

## Output format

Return JSON array (one entry per draft). 1-2 image suggestions per draft.

```json
{
  "angle": "Treuhand Beleg-Eingang Automation",
  "image_suggestions": [
    { "kind": "auto-svg", "spec": {...}, "rationale": "..." },
    { "kind": "existing-asset", "path": "...", "rationale": "..." }
  ]
}
```

## What this skill does NOT do

- It does NOT generate the actual SVG file. That's a future automation (suggested spec → SVG renderer). Phase-1 output is the SPEC only.
- It does NOT crawl the file system to verify `existing-asset` paths. You suggest reasonable paths; PR Director validates existence before writing to Notion.
- It does NOT pick from external image services. We are anti-stock by policy.
