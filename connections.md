# Connections

Registry of every system the AIOS can reach, mapped to the 7 universal data domains. Update whenever a new tool gets wired (or unwired). The `/audit` skill reads this file to score the **Connections** axis.

**Mechanism legend:** `mcp` (MCP server), `n8n` (native node inside an n8n workflow), `script` (Python/Bash in `tools/` hitting an API), `hook` (shell script in `.claude/hooks/`), `key+ref` (`.env` key + `references/<tool>-api.md` guide), `not yet connected`.

**RW** = Read+Write (can mutate). **R** = Read-only.
